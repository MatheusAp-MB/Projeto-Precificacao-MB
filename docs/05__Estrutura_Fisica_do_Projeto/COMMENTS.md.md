# COMMENTS.md

## O que é?

Arquivo de documentação na raiz do projeto que define a **convenção
de comentários** adotada em todo o código.

---

## Por que existe na raiz?

Fica na raiz do repositório para ser a primeira coisa que qualquer
desenvolvedor ou LLM vê ao abrir o projeto — sem precisar entrar
no MkDocs ou procurar em subpastas.

---

## Conteúdo

Define as 5 tags de comentário usadas com a extensão **Better Comments**,
a sintaxe correta para cada tipo de arquivo, regras de comentários
multiblocos e exemplos práticos.
