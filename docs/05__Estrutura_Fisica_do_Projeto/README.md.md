# README.md

## O que é?

Arquivo de documentação na raiz do projeto. É o **"não podemos esquecer"**
do projeto — contém regras críticas e instruções essenciais.

---

## Por que existe na raiz?

É o arquivo padrão de documentação de qualquer repositório Git.
O GitHub e o GitHub Desktop o exibem automaticamente ao abrir o repositório.

---

## O que contém?

- Instrução para LLMs — como sincronizar e qual branch usar
- Descrição do projeto
- Regras sobre MkDocs e o espelho vivo
- Estrutura de branches
- Stack tecnológica
- Passo a passo de configuração em um PC novo
- Arquivo `.env` necessário
- Convenção de comentários resumida
- Convenção de commits

---
