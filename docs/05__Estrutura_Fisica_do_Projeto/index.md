# Estrutura Física do Projeto

Esta seção é o **espelho vivo** do projeto. Cada arquivo e pasta que existe
no VSCode tem uma página correspondente aqui, explicando sua função,
por que existe e o que não deve ser alterado.

---

## Regra do espelho vivo

- Criou um arquivo no projeto → cria a página correspondente aqui
- Removeu um arquivo do projeto → remove a página correspondente aqui
- Criou uma pasta no projeto → cria a pasta correspondente aqui
